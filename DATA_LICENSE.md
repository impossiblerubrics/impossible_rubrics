# Dataset and source-text rights

The code license does not relicense the benchmark data or external evidence.

The maintainers must select a license for the questions, certificates, fixed
answers and other annotations they control. **That dataset license is not yet
assigned in this snapshot.** No permission is inferred for material
owned by others.

The frozen dataset contains 937 evidence passages, including 12 marked synthetic
by the provenance rules. The source snapshot has no structured license fields
for these passages. Their URLs, citations, fetch-verification status, word counts
and text hashes are listed in `docs/source_manifest.json`; redistribution status
remains explicitly pending.

A public URL, a successful fetch, an arXiv/PMC host or a short excerpt does not
by itself settle redistribution rights. Keep existing source attribution and
applicable source terms. Source-specific redistribution rights remain under
review. Repository visibility does not supply a blanket license or determine
a legal basis for downstream reuse.

Do not silently delete, paraphrase or replace evidence to resolve a rights issue:
the exact frozen packet defines the task and its certificate. A citation-only
or rights-resolved subset must be labeled as such and cannot be advertised as a
complete reproduction of the original benchmark.

For corrections, identify the task ID, document ID and source URL when contacting
the maintainers through the project page. Do not post private personal details
or API credentials in an issue.
